# Guidelines de conception des illustrations PPC

**Version :** v1.0  
**Statut :** document maître de référence  
**Objet :** formaliser les règles visuelles, éditoriales et de production à respecter pour concevoir des illustrations cohérentes pour la Pérennité Programmée Circulaire (PPC), quel que soit l’outil ou l’IA utilisé.

---

## 1. Rôle de ce document

Ce document est la **source de référence** pour toute nouvelle illustration PPC.

Il doit être utilisé pour :

- cadrer la direction visuelle ;
- guider une IA générative ;
- briefer un designer ou un illustrateur ;
- vérifier la cohérence entre plusieurs illustrations ;
- éviter que chaque nouvelle image parte dans une direction graphique différente.

Les illustrations PPC doivent être conçues comme les éléments d’une **même famille visuelle**.

La cohérence globale prime sur l’originalité isolée d’une image.

---

# 2. Principe général : pédagogie avant décoration

Une illustration PPC doit d’abord **faire comprendre une idée**.

Elle ne doit pas être conçue comme une simple image décorative.

Avant de produire une image, il faut donc formaliser :

1. **le message pédagogique principal** ;
2. **ce que le lecteur doit comprendre en quelques secondes** ;
3. **les relations causales, circulaires ou systémiques à représenter** ;
4. seulement ensuite, la composition graphique.

Règle générale :

> **partir du message pédagogique, puis choisir la métaphore graphique.**

Éviter de partir d’un pictogramme, d’un style ou d’une composition séduisante si ceux-ci ne servent pas directement le raisonnement.

---

# 3. Direction artistique PPC

## 3.1. Positionnement visuel

Le langage visuel recherché peut être décrit comme :

> **schéma éditorial stylisé à l’esthétique de dessin technique / architectural.**

Il doit évoquer :

- la précision ;
- l’ingénierie ;
- la robustesse ;
- le temps long ;
- la circularité ;
- l’industrie inscrite dans le vivant ;
- une approche institutionnelle mais non froide.

Le rendu doit rester :

- sobre ;
- élégant ;
- lisible ;
- intemporel ;
- légèrement sensible / dessiné ;
- non photoréaliste.

## 3.2. Ce qu’il faut éviter

Éviter :

- le photoréalisme ;
- les rendus 3D trop détaillés ;
- les objets très réalistes qui détournent l’attention du raisonnement ;
- l’esthétique “slide corporate” générique ;
- les illustrations type banque d’icônes ;
- les effets décoratifs sans rôle pédagogique ;
- les ombres ou volumes trop réalistes ;
- les palettes multicolores ;
- les styles trop “startup tech” ou trop “infographie marketing”.

---

# 4. Palette chromatique

## 4.1. Fond

Le fond de référence est **ivoire / crème très clair**.

Il doit donner une sensation :

- chaleureuse ;
- sobre ;
- éditoriale ;
- naturelle ;
- compatible avec le site PPC.

Éviter le blanc pur si cela crée une rupture avec les illustrations déjà validées.

## 4.2. Bleu foncé de référence

Les éléments structurels utilisent un **bleu foncé de référence**.

Ce bleu doit être utilisé de manière cohérente pour :

- les textes ;
- les titres ;
- les contours ;
- les dessins techniques ;
- les pictogrammes ;
- les flèches structurelles ;
- les cadres ;
- les numéros ;
- les repères graphiques.

Règle critique :

> **le ton de bleu doit rester cohérent d’une illustration à l’autre.**

Ne pas réinterpréter librement la teinte sur chaque nouvelle image.

Une dérive vers un bleu plus clair, plus saturé ou plus gris peut sembler acceptable isolément mais créer une rupture immédiate lorsque plusieurs illustrations sont affichées sur la même page.

## 4.3. Ocre / orange : couleur de la valeur

L’ocre / orange est la couleur sémantique réservée à la **valeur**.

Elle peut représenter :

- la valeur contenue dans les matières premières ;
- la valeur incorporée par la fabrication ;
- la valeur contenue dans un produit ou un actif ;
- la valeur dans les composants ;
- la valeur conservée ;
- la valeur perdue en fin de vie ;
- une ligne de flux explicitement nommée **« valeur »** ;
- les boucles ou retours lorsque ceux-ci représentent un maintien de valeur.

Règle critique :

> **l’ocre ne doit pas devenir une simple couleur décorative.**

Chaque utilisation doit avoir une signification explicite liée à la valeur.

## 4.4. Couleurs supplémentaires

Aucune couleur supplémentaire ne doit être introduite sans justification conceptuelle forte.

Par défaut, la palette doit rester limitée à :

- ivoire ;
- bleu foncé ;
- ocre / orange ;
- éventuellement quelques gris très discrets pour les repères secondaires.

---

# 5. Langage graphique

## 5.1. Dessins et pictogrammes

Les objets doivent être :

- stylisés ;
- synthétiques ;
- lisibles ;
- plus proches d’un dessin technique éditorial que d’un rendu réaliste.

Utiliser :

- traits fins ;
- vues éclatées lorsque cela sert le raisonnement ;
- silhouettes simples ;
- petites annotations techniques ;
- repères de construction discrets ;
- quelques détails industriels choisis avec parcimonie.

## 5.2. Lignes de construction

Des lignes de construction légères peuvent être utilisées pour rappeler l’univers du dessin industriel ou architectural.

Elles doivent rester :

- secondaires ;
- légères ;
- peu contrastées ;
- non décoratives si elles nuisent à la lecture.

## 5.3. Épaisseur des traits

Les traits de même statut doivent partager :

- la même couleur ;
- la même épaisseur ;
- le même style.

Une différence visuelle doit toujours correspondre à une différence de sens.

Exemple : si trois cercles ont un contour fin bleu foncé, un quatrième cadre conceptuellement équivalent ne doit pas avoir un contour plus sombre ou plus épais sans raison.

## 5.4. Éléments équivalents

Les éléments conceptuellement équivalents doivent être traités de manière homogène :

- numéros ;
- badges ;
- encadrements ;
- pictogrammes ;
- flèches ;
- légendes ;
- titres.

Règle :

> **ne jamais créer une hiérarchie graphique qui n’existe pas dans le concept.**

---

# 6. Typographie et textes dans les illustrations

## 6.1. Style

La typographie doit être :

- éditoriale ;
- élégante ;
- lisible ;
- sobre ;
- cohérente avec l’univers du site.

Les grands titres peuvent avoir un caractère éditorial / institutionnel.

Les annotations techniques doivent rester simples et très lisibles.

## 6.2. Quantité de texte

Une illustration PPC ne doit pas chercher à reproduire tout le contenu éditorial de la page.

Le texte doit être limité à :

- titres ;
- verbes-clés ;
- étapes ;
- annotations pédagogiques courtes ;
- légendes nécessaires à la compréhension.

Éviter les paragraphes longs à l’intérieur de l’image.

## 6.3. Textes décoratifs

Supprimer les :

- slogans d’ambiance ;
- signatures périphériques ;
- phrases de remplissage ;
- textes purement décoratifs.

Règle :

> **tout texte présent dans une illustration doit justifier sa présence pédagogiquement.**

---

# 7. Flux, flèches et circularité

## 7.1. Les flux doivent porter du sens

Une flèche doit toujours répondre à une question claire :

- que circule-t-il ?
- dans quel sens ?
- pourquoi ?
- s’agit-il d’un flux physique, économique, informationnel ou de valeur ?

Éviter les flèches génériques ajoutées simplement pour donner du mouvement.

## 7.2. Préférer les boucles lorsque le modèle est circulaire

La PPC ne doit pas être représentée visuellement comme une simple chaîne linéaire lorsque le message concerne la pérennité, la circularité ou la conservation de valeur.

Privilégier :

- boucles ;
- retours ;
- flux réciproques ;
- relations bidirectionnelles.

## 7.3. Ligne de valeur

Lorsque la valeur est au cœur du message, privilégier une **ligne ocre continue** clairement identifiable.

Cette ligne peut :

- traverser plusieurs étapes ;
- se maintenir ;
- reboucler ;
- porter des flux aller et retour ;
- se dégrader ou se rompre lorsque la valeur est perdue.

Règle :

> **si la ligne de valeur peut porter une information de flux, éviter de rajouter des flèches redondantes.**

Une ligne existante doit être exploitée sémantiquement plutôt que doublée par d’autres signes.

---

# 8. Comparaisons entre modèles

Lorsqu’une illustration compare deux systèmes, les éléments communs doivent être **strictement comparables**.

Exemples :

- même usine ;
- même taille ;
- même position relative ;
- même objet ;
- même style ;
- même point de départ des flux.

Les différences visuelles doivent porter uniquement sur ce que l’on souhaite comparer.

Règle :

> **éliminer les différences graphiques parasites qui pourraient être interprétées comme une différence conceptuelle.**

---

# 9. Représenter la systémique PPC

## 9.1. Ne pas tout mettre sur le même plan

Les concepts PPC n’ont pas nécessairement le même rôle.

Avant de dessiner plusieurs blocs, déterminer si la relation est :

- séquentielle ;
- réciproque ;
- hiérarchique ;
- transverse ;
- causale ;
- circulaire ;
- structurante.

La composition spatiale doit traduire cette logique.

## 9.2. Exemple des quatre piliers

La représentation stabilisée des quatre piliers PPC suit cette logique :

- **1 ↔ 2 ↔ 3** : articulation logique et réciproque ;
- **4** : couche transverse de pilotage, traçabilité, valorisation et financement.

Cela signifie que le pilier 4 ne doit pas être représenté comme une simple quatrième étape après le pilier 3.

Ce principe est important au-delà de ce cas :

> **un élément transverse doit être représenté comme transverse, pas artificiellement intégré à une séquence.**

---

# 10. Composition

## 10.1. Aération

Les illustrations doivent rester aérées.

Préserver :

- de l’espace blanc ;
- des marges ;
- une séparation claire des idées ;
- des zones de respiration entre les éléments.

Éviter :

- l’empilement d’icônes ;
- la densité excessive ;
- les cadres trop nombreux ;
- les textes serrés ;
- les compositions qui ressemblent à un tableau de bord.

## 10.2. Lecture immédiate

L’image doit fonctionner à deux niveaux :

1. **en quelques secondes** : comprendre le message principal ;
2. **en lecture attentive** : découvrir les détails et annotations.

Si le message global n’est visible qu’après avoir lu tous les textes, la composition est trop complexe.

## 10.3. Format web

Pour les illustrations destinées au site :

- privilégier un format horizontal lorsque le raisonnement est séquentiel ou systémique ;
- vérifier la lisibilité une fois intégré dans la page ;
- éviter les textes trop petits ;
- prévoir que l’image puisse être redimensionnée sur desktop et mobile.

---

# 11. Workflow recommandé

## Étape 1 — Cadrer le message

Écrire avant génération :

- objectif pédagogique ;
- message clé ;
- structure conceptuelle ;
- éléments à montrer ;
- éléments à ne pas montrer ;
- rôle des couleurs ;
- sens des flux.

## Étape 2 — Générer des prototypes visuels

Utiliser la génération d’image comme outil d’exploration pour :

- tester des compositions ;
- comparer des métaphores ;
- converger rapidement sur une direction esthétique.

Ne pas chercher à obtenir immédiatement un livrable final parfait.

## Étape 3 — Itérer sur la compréhension

Évaluer les prototypes en priorité sur :

- la clarté ;
- la logique des flux ;
- la compréhension du message ;
- la cohérence avec les illustrations existantes.

Corriger la structure avant de corriger les détails esthétiques.

## Étape 4 — Harmoniser

Comparer toute nouvelle illustration aux illustrations PPC déjà validées :

- bleu ;
- ocre ;
- épaisseur de traits ;
- typographie ;
- niveau de détail ;
- style des pictogrammes ;
- fond ;
- densité visuelle.

## Étape 5 — Finaliser

Si nécessaire :

- retouche manuelle ;
- reconstruction vectorielle ;
- SVG propre ;
- adaptation pour le web ;
- optimisation du poids du fichier.

La génération directe d’un SVG par IA n’est pas la méthode privilégiée pour la direction artistique finale : elle peut être utile techniquement, mais donne souvent un rendu esthétique inférieur à une phase d’exploration par génération d’image suivie d’une finition dédiée.

---

# 12. Checklist de validation

Avant validation d’une nouvelle illustration PPC, vérifier :

- [ ] Le message pédagogique est compréhensible en quelques secondes.
- [ ] La composition reflète correctement la structure conceptuelle.
- [ ] Les relations circulaires ou réciproques ne sont pas artificiellement rendues linéaires.
- [ ] Le fond est cohérent avec le fond ivoire de référence.
- [ ] Le bleu foncé correspond visuellement aux illustrations déjà validées.
- [ ] L’ocre est utilisé uniquement pour représenter la valeur.
- [ ] Les traits et contours ont une épaisseur cohérente.
- [ ] Les éléments équivalents ont le même traitement graphique.
- [ ] Les pictogrammes restent simples et techniques.
- [ ] Les objets ne sont pas trop réalistes.
- [ ] Les textes sont courts et utiles.
- [ ] Aucun texte périphérique décoratif inutile n’est présent.
- [ ] Les flèches et flux ont une signification explicite.
- [ ] Il n’existe pas de signes graphiques redondants.
- [ ] L’image reste lisible une fois intégrée dans le site.
- [ ] L’image a été comparée visuellement aux autres illustrations PPC déjà validées.

---

# 13. Brief générique à donner à une IA

Le bloc suivant peut être réutilisé comme base de prompt pour toute IA générative :

> Concevoir une illustration pédagogique pour la Pérennité Programmée Circulaire (PPC), cohérente avec l’identité visuelle PPC existante.
>
> Direction visuelle : schéma éditorial stylisé, inspiré du dessin technique / architectural, fond ivoire, composition aérée, traits fins et précis, rendu institutionnel mais sensible, non photoréaliste.
>
> Utiliser un bleu foncé cohérent pour tous les textes, contours, pictogrammes et dessins techniques. Ne pas dériver vers un bleu clair. Utiliser l’ocre / orange uniquement pour représenter la valeur et son cheminement.
>
> Les objets doivent être stylisés, synthétiques et lisibles. Éviter les effets 3D réalistes, les palettes multicolores, l’esthétique corporate générique et les éléments décoratifs inutiles.
>
> Les flux et les flèches doivent avoir une signification explicite. Lorsque le concept est circulaire ou réciproque, privilégier les boucles et flux de retour plutôt qu’une chaîne linéaire.
>
> Les éléments conceptuellement équivalents doivent partager la même couleur, la même épaisseur de trait et le même traitement graphique.
>
> Le message principal doit être compréhensible en quelques secondes, avec des annotations courtes et pédagogiques.

À ce bloc générique doivent ensuite être ajoutés :

- le message spécifique de l’illustration ;
- les éléments à représenter ;
- la structure des relations ;
- les textes à afficher ;
- les contraintes propres au cas d’usage.

---

# 14. Principe final

La cohérence PPC ne repose pas sur un style graphique appliqué superficiellement.

Elle repose sur l’alignement entre :

- le **sens** ;
- la **structure du système représenté** ;
- les **flux** ;
- les **conventions de couleur** ;
- le **langage graphique** ;
- et la **continuité visuelle entre toutes les illustrations**.

Règle de référence :

> **une illustration PPC doit être compréhensible seule, mais immédiatement reconnaissable comme appartenant à la même famille que les autres illustrations PPC.**
